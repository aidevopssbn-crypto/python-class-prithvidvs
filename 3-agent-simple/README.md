# Python Class Training

A minimal Jupyter-based course repo for Python basics and LLM agent practice.

## Topics covered

- Variables, basic types, and f-strings
- Control flow and functions
- Lists, dictionaries, and nested data
- JSON and HTTP requests
- Async and structured Python patterns
- Prompt engineering fundamentals
- LangChain agent evolution and tool-based workflows

## Recommended order

1. Start with notebooks in `0-python/`
2. Then continue into `3-agent-simple/`
3. Use a local `.env` file for API keys
